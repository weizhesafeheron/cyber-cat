# 0002 - 纯程序化像素猫（渲染与动画均不用精灵图）

日期：2026-07-28
状态：已采纳（经 prototype ①② 验证）

## 背景

猫的身份模型是「品种 + Seed」，每只猫外观独一无二，预绘制精灵图无法覆盖 Seed 空间。
动画要求真实感（呼吸、尾巴物理、眨眼等微动作）。

## 决策

外观与动画全部程序化：

- 逐像素光栅化（72×56 像素缓冲，椭圆部件 + 花纹着色函数 + 描边 pass），品种差异做在结构参数上（耳朵形状/位置/外张角、坐姿宽窄、花纹算法），不是换色。
- 动画为参数曲线姿态系统（站/坐/趴/蜷四种体型 + 连续参数），微动作独立成层（眨眼/耳抖/歪头/尾巴波动/呼吸）。

## 理由

- prototype ① 验证了可爱度可接受（用户判决：可以）；prototype ② 验证了动作真实感（用户判决：达标）。
- 程序化让性格参数能贯穿到行为与动作（懒猫走得慢、活跃猫扑得急），精灵图做不到连续个体差异。
- 曾评估的备选：部件库拼装（组合爆炸、逐帧工作量大）、混合方案 C（手绘脸部件）作为兜底未启用。

## 影响

- 美术迭代 = 调渲染代码，无美术资产管线。
- 新增品种的成本是一组结构参数 + 花纹函数分支。
- 若未来引入不可程序化的复杂动作，再评估混合方案。
