# 0001 - 离线推演而非服务器持续模拟

日期：2026-07-28
状态：已采纳

## 背景

游戏要求猫 24h 不间断生活，玩家不在时状态也在变化。
两条路线：纯前端离线推演（状态 = 上次快照 + 经过时间的纯函数），或服务器逐 tick 持续模拟。

## 决策

采用离线推演。
模拟层写成确定性纯函数，输入快照与时间差，输出当前状态与期间事件列表（猫咪日记的数据源）。
游戏时间与现实时间 1:1，不加速。

## 理由

- 单人玩法下两者体验完全等价，离线推演不需要服务器、部署与运维。
- 纯函数模拟器可测试、可回放，且日后如需「多人围观」「主动推送」，同一模拟器可直接搬到服务端跑，不是单行道。
- 代价：离开期间无法向玩家推送（猫不能求救），死亡链因此设计了 3~4 天的缓冲。

## 影响

- 模拟层与渲染层必须严格分离。
- 存档只需 localStorage（品种 + Seed + 出生时间 + 最近快照）。
- 所有随时间的状态变化必须写成时间的函数，禁止依赖帧循环累积。
