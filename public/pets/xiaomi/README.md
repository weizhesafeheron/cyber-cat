# 小米 A 方案动作资源

- 每个动作是一条 6 格横向、无损 WebP 条带。
- 单格尺寸为 288×224；运行时整格替换，不进行头、身体、四肢的局部拼接。
- 原始画面来自已验收的 ImageGen 小米 Demo；这里只做确定性的透明边缘清理、等比缩放、锚点对齐与打包。
- 15 个动作使用同一缩放比例。除扑跳外，每一格的最低有效像素都对齐逻辑地面线 `y = 50`；跳起、下落和落地的屏幕位移只由运动层负责，避免重复位移。
- 扑跳的首尾帧落在同一地面线上，中间两格保留帧内腾空弧线，因为这个动作的运动层只负责横向位移。
- 条带中的格子是素材库，不等于固定播放顺序。需要咬合物理事件的动作可在 `src/render/xiaomi.ts` 声明逐格顺序与停留时长；落地在接触帧直接取压缩格，并在 450ms 内完成回弹。
- 修改资源后运行 `sh tools/check-xiaomi-actions.sh`，校验条带尺寸、脚底锚点和扑跳弧线。
